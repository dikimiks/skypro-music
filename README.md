# Skypro.Music

Учебный проект музыкального сервиса Skypro.Music.

Проект подготовлен на Vue 3 с использованием Vite. На текущем этапе выполнена декомпозиция готовой разметки на Vue-компоненты, подключены статические файлы и добавлены тестовые данные треков.

## Технологии

- Vue 3
- Vite
- JavaScript
- CSS
- SVG

## Компоненты

`App.vue` — основной экран приложения и сборка основных блоков.

`Navbar.vue` — логотип, бургер и навигационное меню.

`FilterControls.vue` — блок фильтров по исполнителю, году выпуска и жанру.

`Playlist.vue` — заголовок списка и вывод треков.

`Track.vue` — отдельный элемент списка треков.

`PlayerBar.vue` — нижняя панель музыкального плеера.

## Данные

Тестовые данные треков находятся в файле `src/data/tracks.js` и подключаются в `App.vue`.

Для каждого трека используются поля:

- `id` — идентификатор;
- `title` — название трека;
- `author` — исполнитель;
- `album` — альбом;
- `duration` — продолжительность;
- `suffix` — дополнительная подпись к названию трека.

## Стили

Стили распределены по соответствующим Vue-компонентам и подключены через `<style scoped>`.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминале.

## Сборка проекта

Для production-сборки:

```bash
npm run build
```

Для просмотра собранного проекта:

```bash
npm run preview
```

## Текущий этап

На данном этапе проект содержит подготовленную структуру Vue-приложения, готовую разметку музыкального сервиса, декомпозированную на компоненты, статические изображения и локальный файл с треками.

Интеграция с API, авторизация, Pinia, полноценная логика фильтрации и функциональность аудиоплеера относятся к следующим этапам задания.
