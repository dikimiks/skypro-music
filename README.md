# Skypro.Music

Учебный проект музыкального сервиса Skypro.Music, разработанный в рамках курса SkyPro.

Приложение позволяет просматривать музыкальный каталог, искать и фильтровать треки, управлять воспроизведением, авторизовываться и работать с избранными композициями.

## Технологии

- Nuxt 3
- Vue 3
- JavaScript
- Pinia
- CSS
- Vitest

## Возможности

- Просмотр каталога музыкальных треков.
- Поиск по названиям треков.
- Фильтрация по исполнителям и жанрам.
- Сортировка музыкального каталога.
- Воспроизведение, пауза и управление музыкальным плеером.
- Авторизация и регистрация пользователей.
- Добавление и удаление треков из избранного.
- Страница избранных треков.
- Управление состоянием приложения с помощью Pinia.
- Переключение темы оформления.
- Адаптивная верстка.
- Обработка состояний загрузки и ошибок.
- Страница 404.
- Тестирование отдельных функций.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по локальному адресу, указанному в терминале.

## Проверка и сборка

Запуск тестов:

```bash
npm run test
```

Запуск тестов с покрытием:

```bash
npm run test:coverage
```

Production-сборка:

```bash
npm run build
```

Просмотр production-сборки:

```bash
npm run preview
```

## Структура проекта

- `components/` — компоненты интерфейса.
- `pages/` — страницы приложения.
- `layouts/` — макеты.
- `store/` — хранилища Pinia.
- `composables/` — composables.
- `utils/` — вспомогательные функции.
- `assets/` — стили и ресурсы.
- `public/` — статические файлы.
- `tests/` — тесты.
